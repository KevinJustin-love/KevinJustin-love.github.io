# Jiajun Peng · Personal Research Homepage

This repository contains the source for [kevinjustin-love.github.io](https://kevinjustin-love.github.io/), a lightweight personal homepage for Jiajun Peng, an undergraduate Data Science student at USTC.

## Focus

The site introduces my research interests in:

- World models
- Embodied intelligence
- Vision-language-action models
- Spatial intelligence
- Video understanding and multimodal learning

## Design

The page uses a dark AI Lab visual language:

- Deep GitHub-style background
- Electric blue and teal accents
- Responsive layout for desktop and mobile
- No build tools or external JavaScript dependencies

## Local preview

Because this is a static site, it can be previewed with any local HTTP server. For example, run: python -m http.server 8000

Then open http://localhost:8000 in a browser.

## Deployment

The site is deployed through GitHub Pages from the main branch and the repository root. After pushing changes, GitHub Pages publishes the updated index.html automatically.
